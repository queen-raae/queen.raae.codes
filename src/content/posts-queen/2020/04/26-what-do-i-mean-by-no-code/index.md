Hello,

My definition is a broad one.

Anything that you would have asked a developer for help with 5-10 years back, but that you today can solve yourself by using tools and services.

If you have created a website using a service like [Squarespace](https://www.squarespace.com/), [Wix](https://www.wix.com/), [Carrd](https://carrd.co/), or [WordPress](https://wordpress.com/), that is no code to me.

If you have automated a workflow using [Zapier](https://zapier.com/) or [IFTTT](https://ifttt.com/) (If This Then That) to alleviate a tedious but crucial step in your business, that is no code to me.

If you have gotten a webshop up and running without the help of a developer, that is no code to me.

If you have made an app with the help of [Glide](https://www.glideapps.com/), [Bubble](https://bubble.io/), or [AppSheet](https://www.appsheet.com/), that is no code to me.

- Benedicte
