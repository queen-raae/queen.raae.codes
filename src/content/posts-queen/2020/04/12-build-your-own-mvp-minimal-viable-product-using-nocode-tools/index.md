This one is for you!

There is a new trend in town: **#nocode**.

Over the last years, there has been an explosion in #nocode tools.

You have probably heard of [Squarespace](https://www.squarespace.com/) that makes it possible to create a website without knowing how to code.

But there are also services to support:

- booking ([Calendly](https://calendly.com/)),
- online course selling ([Podia](https://www.podia.com/)),
- streaming ([Twitch](https://www.twitch.tv/)),
- making money off an online magazine ([Ghost](https://ghost.org/)),
- forums ([Discord](https://discordapp.com/)),
- and so many many more.

You can even make **apps** with #nocode. [Glide](https://www.glideapps.com/) lets you create apps powered by [Google Sheets](https://www.google.com/sheets/about/). How cool is that?

For extra credit, use [Zapier](https://zapier.com/) to connect them all together!

With some imagination, you can twist and combine these tools to create a Minimal Viable Product (MVP) for almost any idea you might have.
